# 📘 Programación — 4to Año

## Introducción a Python + Proyecto Final: Videojuego

Este repositorio contiene los contenidos y materiales de la materia. Vamos a recorrer los fundamentos de Python y, con esas herramientas, construir nuestro propio videojuego.

---

## 🎯 Objetivos de la materia

- Aprender los conceptos fundamentales de programación usando Python.
- Desarrollar lógica algorítmica y pensamiento computacional.
- Aplicar todo lo aprendido en un proyecto integrador: un **videojuego**.

---

## 🐍 Unidad 1: Introducción a Python

- ¿Qué es Python? Instalación y entorno de trabajo
- Variables y tipos de datos (`int`, `float`, `str`, `bool`)
- Entrada y salida de datos (`input()`, `print()`)
- Operadores aritméticos, relacionales y lógicos

## 🔀 Unidad 2: Estructuras de control

- Condicionales (`if`, `elif`, `else`)
- Bucles (`while`, `for`)
- `break`, `continue` y control de flujo

## 🧩 Unidad 3: Funciones

- Definición de funciones (`def`)
- Parámetros, argumentos y valores de retorno
- Alcance de variables (variables locales y globales)
- Funciones con valores por defecto

## 📦 Unidad 4: Estructuras de datos

- Listas: creación, indexado, métodos y recorrido
- Tuplas: características y diferencias con las listas
- Diccionarios: claves, valores, métodos y recorrido
- Combinación de estructuras (listas de diccionarios, etc.)

---

## 🎮 Proyecto Final: Videojuego

Con los contenidos de las unidades anteriores como base, vamos a diseñar y programar un **videojuego** en Python, aplicando:

- Estructuras de control para la lógica del juego
- Funciones para organizar el código
- Listas y diccionarios para manejar datos del juego (jugadores, puntajes, objetos, niveles, etc.)

### Etapas del proyecto

1. Idea y diseño del juego (mecánica, reglas, objetivo)
2. Programación de la lógica base
3. Incorporación de gráficos/interfaz (según la herramienta que usemos: consola, `turtle` o `pygame`)
4. Testeo y mejoras
5. Presentación final

---

## 🛠️ Requisitos

- Python 3.x instalado
- Editor de código (recomendado: VS Code)
- (Opcional, según el proyecto) librería `pygame`
